Women's Safety App — System Architecture

React Native (Expo) · Firebase · Node.js Relay · Twilio · Offline Hardware Link

Mobile App

  • • React Native + Expo (TypeScript)
  • • One-tap SOS with live GPS
  • • Trusted contacts stored in Firestore
  • • Runs on Android, iOS and Web

Relay Server

  • • Node.js + Express
  • • Ingests app GPS on SOS
  • • Feeds the offline hardware link
  • • Twilio SMS proxy endpoint

Alerting

  • • SMS via Twilio with Maps link
  • • Online path: app → Twilio direct
  • • Offline path: hardware → relay → Twilio
  • • Emergency numbers blocked by design
